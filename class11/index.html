Vehicle Inheritance Demo

  1. What is inheritance?
    • Inheritance allows us to reuse specified behaviour and structure across different object types.
  2. Why do we use Animal.call(this, name) or Vehicle.call(this, brand) in child constructors?
    • This calls/runs the parent constructor for the child prototype.
  3. Why do we use Object.create(...)?
    • This connects the child prototype to the parent prototype and allows the child to access the parent methods.
  4. Why do we reset the constructor property?
    • Not too sure. But I think it might be to ensure that the child prototype uses its own constructor rather than the one inherited from parent.
  5. What is the difference between inherited methods and child-specific methods?
    • Parent methods are accessible by all types that are children of the parent.
    • Child-specific methods are only accessible by that specific child and its own children but not other children.
  6. How does class ... extends ... relate to prototypes?
    • I believe it connects the current class to the specified parent and that parent's methods.
  7. Compare constructor-function inheritance to class inheritance.
    • Both version rely on the parent and call on it to take on its properties and methods.
    • Class inheritance is easier for me to read since all of the methods and properties related to the class are grouped together.
    • The constructor-function version uses the prototype keyword to show the different relationships of the prototype chain. The class version is written in a more implicit way without the keyword.
