Reflection

  1. What is the purpose of try/catch?
    • To set up a flow that will take an error that would essentially break the program and do something different to indicate what the error is without breaking the program.
  2. What does throw new Error(...) do?
    • When it runs, it creates a new error with the message being what is between the "()". This new error will then get caught by the catch and execute the code within the catch.
  3. Why do we check response.ok in fetch code?
    • To establish whether or not the fetch was successful or not. This would allow us to throw an error if it was not and set up a new flow to handle this error.
  4. What is the difference between sync error handling and Promise .catch()?
    • Synchronous error handling with catch occur in chronological order while the promise .catch() is asynchronous and only executes once the promise is resolved.
  5. What is finally useful for?
    • It is code that will always run whether the try successeds or not. It is good to reset UI elements in the page to a neutral state.
