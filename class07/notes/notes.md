## Progressive Enhancements
> [!definition]
> design approach (philosophy) to building web interface
> -> build basic first and then make it richer with CSS & JS

> **HTML**: Structure & Meaning
> **CSS**: Presentation
> **JS**: Enhancement & Interactivity
### The base
- Meaningful HTML
- Core content
- Basic navigation / interactions
### Enhancements
- Styling
- Dynamic behaviour
- Async loading
- Nicer feedback
- Richer layout
