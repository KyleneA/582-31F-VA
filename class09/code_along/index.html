Reflection

  1. What is the purpose of type="module" in HTML?
    • The type module attribute for the script tag in HTML tells the browser that the script that will be loaded is a module
    • Also tells the browser that the script code should only be executed after the entirety of the HTML is parsed
  2. Why is it useful to separate fetchUsers() into api.js?
    • It allows us to separate the parsing of the response from the execution of the promise once fetched, allowing us to more meaningfully separate the steps relating to fetching API data.
  3. Why is it useful to separate rendering into ui.js?
    • This allows us to reduce the size of the app.js file while also adding meaningful separation between functions used throughout the program. This can be helpful when debugging.
  4. What would happen if everything stayed in one file as the project grows?
    • As the project becomes more complex, the app.js file will get increasingly larger. This can lead to the file being less readable, harder to navigate, and harder to debug.
  5. What is the difference between exporting and importing?
    • Exporting allows us to create code (functions, variables, or classes) that we can use and reuse in other files in the project.
      • It tells JS that the code can be used elsewhere.
    • Importing what allows us to use the code we created (functions, variables, or classes) in another file in a different file.
      • It tells JS that we want to use the code from the other file in the current one.
