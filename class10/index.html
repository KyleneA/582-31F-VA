Reflection Qs

What problem do prototypes solve?

Prototypes allows us to centralize the methods and properties that are shared between several objects. It allows us to reduce repetition by only needing to write the code for the method or property once.

What is the difference between an own property and a prototype method?

The prototype method and prototype property are automatically applied to all instances of the object using the construction function. On the other hand, own properties are unique to the object instance and do not affect other instances of the object created with the constructor.

Where does JavaScript look if a method is not found directly on an object?

It looks to the prototype of the object.

Why is book1.displayInfo === book2.displayInfo useful evidence?

This code demonstrates that both the methods are the exact same in both value and type (strict equality).

What happened when you changed book1.category?

It created a shadow of the prototype property.

Why is it better to put shared behavior on the prototype instead of inside every object?

It reduces the possibility of introducing bugs during coding and helps reduce the size of the file.

Challenge 3: Explain what changed before and after setting book2.genre = 'Romance';

Until the I changed the genre for book2, it did not have it's own genre property because it is a shared property from the prototype. Once changed, the genre property became its own.
